Privacy policy

Last updated: November 9, 2026

Order Agent is a personal tool used only by its owner, on the owner's own computer. It is not offered to anyone else.

What it accesses

  • Gmail, read-only (gmail.readonly): only to find emails about the owner's online orders, shipping and deliveries.
  • Delivery text messages on the owner's Mac.

What it does with the data

  • It extracts order details (shop, items, order and tracking numbers, delivery status, pickup point) and shows them to the owner in a private app.
  • Tracking numbers are sent to carriers' tracking services to get the parcel's status.
  • Email text is processed with Claude (Anthropic) to understand which messages are about orders.

What it never does

  • It never sends, deletes or modifies emails.
  • It never sells, shares or transfers Google user data to third parties for advertising or any other purpose.
  • Its use of data received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Data is stored only on the owner's Mac. Access can be revoked at any time from the Google Account's security settings, and deleting the app's data folder removes everything.
